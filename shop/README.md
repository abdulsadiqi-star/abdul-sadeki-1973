# فروشگاه اینترنتی کالانو

نمونه‌ی یک فروشگاه اینترنتی فارسی و راست‌به‌چپ به سبک دیجی‌کالا، با HTML و CSS و جاوااسکریپت خالص.
به هیچ فریم‌ورک یا مرحله‌ی build نیاز ندارد.

## اجرا

- **ساده‌ترین راه:** فایل `index.html` را در مرورگر باز کنید.
- **با سرور محلی (پیشنهادی):**
  ```bash
  cd shop
  python3 -m http.server 8000
  # سپس در مرورگر: http://localhost:8000
  ```
- **انتشار رایگان روی اینترنت:** پوشه‌ی `shop` را روی GitHub Pages، Netlify یا Vercel قرار دهید.

## امکانات

| بخش | توضیح |
|---|---|
| صفحه اصلی | اسلایدر، نوار مزایا، «پیشنهاد شگفت‌انگیز» با شمارش معکوس، دسته‌بندی‌ها، بنرها، پرفروش‌ترین‌ها، بازدیدهای اخیر، تازه‌ها، برندها |
| هدر | جستجوی زنده با پیشنهاد (با کلیدهای جهت‌نما)، منوی دسته‌بندی بزرگ (مگامنو)، نشان سبد خرید و علاقه‌مندی، حالت تاریک |
| لیست کالاها | فیلتر دسته، برند، محدوده قیمت، فقط موجود، فقط تخفیف‌دار؛ ۷ نوع مرتب‌سازی؛ کشوی فیلتر در موبایل |
| صفحه محصول | گالری، انتخاب رنگ، ویژگی‌ها، جعبه خرید، مشخصات کامل، امتیاز و ثبت دیدگاه، کالاهای مشابه |
| سبد خرید | تغییر تعداد، حذف، محاسبه سود، نوار پیشرفت ارسال رایگان، کد تخفیف (`KALANO10`) |
| ثبت سفارش | ورود با موبایل و کد یکبار مصرف (در نسخه نمایشی `1234`)، فرم آدرس با اعتبارسنجی، ارسال عادی و اکسپرس، پرداخت اینترنتی و در محل |
| حساب کاربری | لیست سفارش‌ها با کد پیگیری، علاقه‌مندی‌ها، خروج |
| طراحی | فونت وزیر، رنگ‌های شاد، سازگار با موبایل و دسکتاپ، حالت روشن و تاریک |

اطلاعات سبد خرید، سفارش‌ها و دیدگاه‌ها در `localStorage` مرورگر ذخیره می‌شود.

## ساختار فایل‌ها

```
shop/
├── index.html      اسکلت صفحه: هدر، فوتر، منوی پایین موبایل
├── css/style.css   همه‌ی استایل‌ها (رنگ‌ها در ابتدای فایل به صورت متغیر تعریف شده‌اند)
├── js/data.js      دسته‌بندی‌ها، کالاها، اسلایدها (داده‌ی نمونه)
└── js/app.js       مسیریابی، صفحات، سبد خرید، فیلترها، ورود و ثبت سفارش
```

## شخصی‌سازی

- **نام فروشگاه:** کلمه‌ی «کالانو» را در `index.html` و `js/app.js` جایگزین کنید.
- **رنگ‌ها:** متغیرهای `--brand` و `--saffron` و بقیه را در ابتدای `css/style.css` تغییر دهید.
- **کالاها:** آرایه‌ی `raw` در `js/data.js` را ویرایش کنید. برای عکس واقعی، فیلد `img` هر کالا را با آدرس عکس پر کنید.
- **هزینه ارسال و کد تخفیف:** ثابت‌های `FREE_SHIP`، `SHIP_NORMAL`، `SHIP_EXPRESS` و `COUPONS` در ابتدای `js/app.js`.

## برای راه‌اندازی واقعی

این نسخه فقط بخش ظاهری (فرانت‌اند) است. برای فروش واقعی به این موارد نیاز دارید:

1. **بک‌اند و پایگاه داده** برای کالاها، کاربران و سفارش‌ها (مثلاً Node.js، Laravel، Django یا ووکامرس).
2. **سرویس پیامک** برای ارسال کد ورود (مثلاً کاوه‌نگار یا ملی پیامک).
3. **درگاه پرداخت** (مثلاً زرین‌پال، آی‌دی‌پی یا درگاه بانکی).
4. **نماد اعتماد الکترونیکی (اینماد)** و ثبت در ساماندهی.
